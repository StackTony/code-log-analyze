### 9 Endpoint Signatures (spec §三)

| Endpoint | Status | Notes |
|----------|--------|-------|
| POST /ingest | ✅ | IngestRequest → IngestResponse, 201 |
| GET /candidates/{repo_id} | ✅ | list[LogPointAPI], 200 |

| POST /revoke/{repo_id} | ✅ | RevokeRequest → 204 |
| GET /log-points/{repo_id} | ✅ | list[LogPointAPI], 200, filters via Query |
| POST /call-context/{repo_id} | ✅ | CallContextRequest → CallContextAPI, 200 |
| GET /health | ✅ | HealthResponse, 200 |
| GET /ready | ✅ | ReadyResponse, 200, DB check |
| GET /metrics | ✅ | Prometheus exposition (fallback + 9100 independent) |

### Mappers Isolation

- `log_point_to_response`: LogPoint dataclass → LogPointAPI Pydantic
- `call_context_to_response`: CallContext dataclass → CallContextAPI
- No direct dataclass imports in routes (clean separation)

### Dependency Injection

- `get_session()`: Generator yields Session + closes in finally (per-request)
- `get_service()`: Constructs RepoLogGraphService with mocked gitnexus/llm/cache (dev-friendly)
- Module-level `_metrics_emitter` singleton prevents Prometheus registry duplication

### Error Handler Coverage

1. UnsafePathError → 400 M1_INVALID_PATH
2. UnsafeUrlError → 400 M1_INVALID_URL
3. RequestValidationError → 422 GENERIC_VALIDATION_ERROR
4. ValidationError (Pydantic) → 422 GENERIC_VALIDATION_ERROR
5. StarletteHTTPException → detail dict passthrough
6. ValueError → 422 GENERIC_VALIDATION_ERROR
7. Exception → 500 GENERIC_INTERNAL_ERROR

### Schemas ConfigDict

All 5 Pydantic schemas use:
```python
model_config = ConfigDict(strict=True, extra="forbid", from_attributes=True)
```
